# Зарплата

Приложение для подсчёта недельной зарплаты (выплата по понедельникам).

- 20% с продаж за смену; если продаж меньше 35 000 ₸ или они ещё не внесены — 7 000 ₸.
- Курьер, оплаченный самому, прибавляется; аванс вычитается.
- Итог разбит по точкам: БЦА, ДАМУ, АРУЖАН, ЖИБЕК, ТУРАН.
- Хранится текущая неделя и 4 прошлые.

## Сервер (Railway)

`node server.js` — отдаёт приложение и хранит данные для синхронизации.
Переменные: `APP_PASSWORD` — пароль для синхронизации, `DATA_DIR` — папка с данными (на Railway — volume `/data`).

## Установка на телефон

1. Открыть адрес сервиса на Railway.
2. iPhone (Safari): «Поделиться» → «На экран Домой». Samsung (Chrome): меню → «Установить приложение».
3. В блоке «Синхронизация» ввести пароль — одинаковый на всех устройствах.

Изменения по каждой неделе сливаются: побеждает версия, изменённая позже.
