# Зарплата

Приложение для подсчёта недельной зарплаты (выплата по понедельникам).

- 20% с продаж за смену; если продаж меньше 35 000 ₸ или они ещё не внесены — 7 000 ₸.
- Курьер, оплаченный самому, прибавляется; аванс вычитается.
- Итог разбит по точкам: БЦА, ДАМУ, АРУЖАН, ЖИБЕК, ТУРАН.
- Хранится текущая неделя и 4 прошлые.

## Сервер (Railway)

`node server.js` — отдаёт приложение, хранит аккаунты (логин + пароль) и данные каждого пользователя.

Переменные:
- `DATA_DIR` — папка с данными (на Railway — volume `/data`);
- `APP_PASSWORD` — пароль старой синхронизации: если ввести его при регистрации, старые данные переносятся в аккаунт (один раз);
- `SEED_DEBTS` — JSON с начальными долгами, добавляется при этом переносе.

## Установка на телефон

1. Открыть адрес сервиса на Railway.
2. iPhone (Safari): «Поделиться» → «На экран Домой». Samsung (Chrome): меню → «Установить приложение».
3. Зарегистрироваться или войти. На чужом устройстве — галочка «Чужое устройство».
4. В блоке «Аккаунт» можно поставить код-пароль из 4 цифр и включить Face ID / отпечаток.
