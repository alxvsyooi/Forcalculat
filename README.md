# Зарплата

Приложение для подсчёта недельной зарплаты (выплата по понедельникам).

- 20% с продаж за смену; если продаж меньше 35 000 ₸ или они ещё не внесены — 7 000 ₸.
- Курьер, оплаченный самому, прибавляется; аванс вычитается.
- Итог разбит по точкам: БЦА, ДАМУ, АРУЖАН, ЖИБЕК, ТУРАН.
- Хранится текущая неделя и 4 прошлые.

## Установка на телефон

1. В GitHub: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
2. Открыть ссылку `https://<логин>.github.io/<репозиторий>/`.
3. iPhone (Safari): «Поделиться» → «На экран Домой». Samsung (Chrome): меню → «Добавить на главный экран» / «Установить приложение».

Данные хранятся на каждом устройстве отдельно; переносить через «Резервная копия».
